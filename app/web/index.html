סיגנלים אחרונים

  • עדיין אין נתונים. לחץ על "סרוק שווקים עכשיו".

איך לחבר דומיין משלך

  1. העלה את השירות לשרת (Render / Railway / VPS).
  2. הגדר Reverse Proxy עם Nginx לכתובת של FastAPI.
  3. צור רשומת DNS מסוג A או CNAME אצל ספק הדומיין.
  4. הפעל תעודת SSL עם Let's Encrypt.
